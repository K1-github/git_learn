# レッスン3: プッシュ 🚀

コミットはまだ「手元(ローカル)の記録」です。
**push** すると、それが GitHub（クラウド）に届き、他の人も見られるようになります。

## リモートとは
GitHub 上のリポジトリを **リモート (remote)** と呼びます。
通常 `origin` という名前が付いています。

```bash
git remote -v      # つながっているリモートを確認
```

## プッシュのコマンド

```bash
git push -u origin <ブランチ名>
```

- `origin` … 送り先（GitHub）
- `<ブランチ名>` … 送るブランチ。今回は `claude/git-basics-learning-o06wr3`
- `-u` … 「今後このブランチは origin と対応」と覚えさせる（初回に付ける）

2回目以降は `git push` だけでOKになります。

## push の前後で確認すること
```bash
git status
```
- `Your branch is ahead of 'origin/...' by N commits` … ローカルが N 個先行 → push が必要
- `Your branch is up to date` … 送信済み

## よくあるつまずき
- **rejected（拒否された）**: GitHub 側に自分が持っていない変更がある。
  → `git pull origin <ブランチ名>` で取り込んでから push し直す。
- **認証エラー**: この Claude Code 環境ではすでに認証済みなので基本起きません。

## 🛠️ やってみよう

1. push が必要か確認
   ```bash
   git status
   ```
2. GitHub に送る
   ```bash
   git push -u origin claude/git-basics-learning-o06wr3
   ```
3. もう一度 `git status`
   → `up to date` になれば成功。GitHub のリポジトリページを開くと、
     あなたのコミットが表示されています。
