# レッスン2: 変更の確認と履歴 🔍

コミットする前に「何が変わったか」を確認する習慣がとても大事です。

## 3つの確認コマンド

```bash
git status     # どのファイルが変わったか（ざっくり全体像）
git diff       # 具体的にどの行が変わったか（詳細）
git log        # これまでのコミット履歴
```

### git status の見方
- `Changes not staged for commit` … 編集したがまだ add していない
- `Changes to be committed` … add 済み（次のコミットに入る）
- `Untracked files` … Git がまだ管理していない新規ファイル

### git diff の見方
```
- 消えた行（赤）
+ 増えた行（緑）
```
`git diff` は「add していない変更」、`git diff --staged` は「add 済みの変更」を表示します。

### git log の便利な形
```bash
git log --oneline           # 1行ずつコンパクトに
git log --oneline --graph   # ブランチの分岐も図で
git log -p                  # 各コミットの中身(diff)も表示
```

## 🛠️ やってみよう

1. 演習ファイルをもう一度編集
   ```bash
   echo "- 2行目もついでに追加" >> playground/my-notes.md
   ```
2. add する前に差分を見る
   ```bash
   git diff
   ```
   → 追加した行が緑の `+` で出る
3. add してから、ステージ済みの差分を見る
   ```bash
   git add playground/my-notes.md
   git diff --staged
   ```
4. コミットして履歴を確認
   ```bash
   git commit -m "メモに2行目を追加"
   git log --oneline
   ```
   → 自分のコミットが並んでいるのが見える
