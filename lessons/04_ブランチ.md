# レッスン4: ブランチ 🌿

**ブランチ**は作業を枝分かれさせる仕組みです。
本流（`main`）を壊さずに、別の「並行世界」で自由に試せます。

```
main:    A---B---C
                  \
feature:           D---E   ← ここで新機能を作り、完成したら main に合流させる
```

## なぜブランチを使う？
- 本番用の `main` を安全に保てる
- 機能ごとに作業を分けられる
- 1つの変更単位でレビュー（＝プルリクエスト）できる

## 基本コマンド

```bash
git branch                     # ブランチ一覧（*が今いる場所）
git switch -c <新ブランチ名>    # 新しいブランチを作って移動
git switch <ブランチ名>         # 既存ブランチに移動
git branch --show-current      # 今いるブランチ名
```

> 補足: 古い教材では `git checkout -b` と書かれますが、今は `git switch -c` が推奨です。

## ブランチ名のつけ方（例）
- `feature/献立追加` … 新機能
- `fix/誤字修正` … バグ・修正
- `docs/readme更新` … ドキュメント

## この学習での注意
この環境では作業ブランチが `claude/git-basics-learning-o06wr3` に決められています。
練習で別ブランチを作るのは自由ですが、**最終的な成果はこのブランチに戻して** push してください。

## 🛠️ やってみよう

1. 今どこにいるか確認
   ```bash
   git branch --show-current
   ```
2. 練習用ブランチを作って移動
   ```bash
   git switch -c practice/branch-taiken
   ```
3. 何か変更してコミット
   ```bash
   echo "- ブランチ練習でのメモ" >> playground/my-notes.md
   git add playground/my-notes.md
   git commit -m "ブランチ練習のメモを追加"
   ```
4. 元のブランチに戻る（さっきの行が消えて見えるのが分岐の効果）
   ```bash
   git switch claude/git-basics-learning-o06wr3
   ```
5. 練習ブランチの変更を取り込みたければ合流(merge)
   ```bash
   git merge practice/branch-taiken
   ```
