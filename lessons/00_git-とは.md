# レッスン0: Git / GitHub とは 🗺️

## Git とは
**Git** は「ファイルの変更履歴を記録するツール」です。
セーブポイントを作りながらゲームを進めるように、作業の節目ごとに状態を保存できます。

- いつ・誰が・何を変えたかが全部残る
- 過去の状態にいつでも戻れる
- 複数人で同じファイルを安全に編集できる

## GitHub とは
**GitHub** は Git のデータを **インターネット上に置いて共有する場所**（サービス）です。
Git が「手元の記録」だとすると、GitHub は「みんなで見られる置き場所」です。

```
[あなたのPC / この環境]              [GitHub（クラウド）]
  ローカルリポジトリ    --- push -->   リモートリポジトリ
                        <-- pull ---
```

## 覚えておきたい用語

| 用語 | 意味 | たとえ |
|------|------|--------|
| リポジトリ (repository) | 履歴を管理するプロジェクトの入れ物 | プロジェクトのフォルダ |
| コミット (commit) | ある時点の変更を記録すること／その記録 | ゲームのセーブポイント |
| ステージング (staging) | コミットに含める変更を選ぶ準備 | 買い物カゴに入れる |
| ブランチ (branch) | 作業を枝分かれさせた並行世界 | 下書き用のコピー |
| プッシュ (push) | ローカルの記録を GitHub に送る | クラウドにアップロード |
| プル (pull) | GitHub の変更を手元に取り込む | クラウドからダウンロード |
| プルリクエスト (PR) | 「この変更を取り込んでほしい」という提案 | 承認をお願いする申請書 |
