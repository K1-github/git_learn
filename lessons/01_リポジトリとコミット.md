# レッスン1: リポジトリとコミット 💾

コミットは Git の心臓です。ここをしっかり体験しましょう。

## 3つのエリアを理解する

Git ではファイルが3つの場所を移動します。

```
[作業ツリー]      [ステージング]        [リポジトリ]
編集中のファイル → git add → 次のコミット候補 → git commit → 履歴に記録
（Working tree）   （Index / Staging）        （History）
```

- **作業ツリー**: あなたが今いじっているファイルそのもの
- **ステージング**: 「次のコミットに入れる」と選んだ変更（買い物カゴ）
- **リポジトリ**: 確定した履歴（レシート = セーブ済み）

## 基本の3コマンド

```bash
git status          # いま何が変わっているか確認する（一番よく使う）
git add <ファイル>   # 変更をステージング（カゴに入れる）
git commit -m "メッセージ"   # ステージングした内容を記録する
```

`git add .` とすると「今の全変更」をまとめてカゴに入れられます。

## 良いコミットメッセージ
- 何をしたかが一目でわかる短い文にする
- 例: `献立にカレーを追加`、`READMEの誤字を修正`
- 「なぜ変えたか」が非自明なら本文に書く

## 🛠️ やってみよう

1. 演習ファイルを開いて1行足す
   ```bash
   echo "- 私が最初に追加した行" >> playground/my-notes.md
   ```
2. 状態を確認する
   ```bash
   git status
   ```
   → `my-notes.md` が「変更あり(modified)」と出るはず
3. カゴに入れる
   ```bash
   git add playground/my-notes.md
   ```
4. もう一度 `git status` を見る
   → 今度は「コミット予定(staged)」に移動している
5. 記録する
   ```bash
   git commit -m "メモに最初の行を追加"
   ```

🎉 これであなたの最初のコミットが履歴に刻まれました。
