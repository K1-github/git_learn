# Git 体験学習リポジトリ 🌱

このリポジトリは **手を動かして Git を学ぶ** ための教材です。
読むだけでなく、実際にコマンドを打ちながら「コミット → プッシュ → プルリクエスト」の流れを体験します。

## 学習の進め方

`lessons/` の中の番号順にレッスンを進めてください。各レッスンには **説明** と **やってみよう（演習）** があります。

| # | レッスン | 学ぶこと |
|---|---------|---------|
| 0 | [00_git-とは.md](lessons/00_git-とは.md) | Git / GitHub とは何か。用語の全体像 |
| 1 | [01_リポジトリとコミット.md](lessons/01_リポジトリとコミット.md) | `git add` / `git commit` の基本 |
| 2 | [02_変更の確認と履歴.md](lessons/02_変更の確認と履歴.md) | `git status` / `git diff` / `git log` |
| 3 | [03_プッシュ.md](lessons/03_プッシュ.md) | ローカルの変更を GitHub に送る |
| 4 | [04_ブランチ.md](lessons/04_ブランチ.md) | ブランチを分けて作業する |
| 5 | [05_プルリクエスト.md](lessons/05_プルリクエスト.md) | 変更をレビューしてもらい取り込む |

## いちばん大事な流れ（これだけ覚える）

```
編集する  →  git add  →  git commit  →  git push  →  Pull Request
（作業）    （準備）     （記録）      （共有）      （提案・レビュー）
```
